# 공간예약 시스템 도우미

회의실·스튜디오·공용 공간을 예약하는 웹페이지와, 그 웹페이지를 조직에 맞게 설치하고 관리하도록 돕는 AI 스킬입니다.

직원은 완성된 웹페이지에서 날짜와 시간을 고르고 예약합니다. AI는 처음 설치할 때 공간 목록과 Google Calendar를 연결하고, 권한을 확인하고, 오류가 생겼을 때 원인을 찾는 일을 돕습니다.

## 준비된 기능

- 예약 가능한 공간 확인
- 여러 사용자의 동시 예약 충돌 방지
- 매주 반복 예약
- 선택적인 Google Meet 생성
- 선택적인 Google Sheets 기록
- 회사 내부 사용자는 로그인만으로 `내 예약` 확인·변경·취소
- 외부 예약 환경에서만 예약 관리 번호 사용
- 예약이 찼을 때 다른 공간과 시간 추천
- 선택적인 예약 확인 이메일
- 관리자용 익명 운영 현황
- 과도한 요청 제한
- 조직 계정만 이용하도록 제한
- 중복 클릭에 의한 이중 예약 방지
- 실패한 작업의 안전한 되돌리기와 부분 성공 안내
- 회사별 설정과 공개 코드를 분리

## AI에게 시작하는 방법

이 폴더 또는 GitHub 주소를 Codex 같은 파일 작업이 가능한 AI에 알려주고 다음과 같이 입력합니다.

> 이 공간예약 시스템 도우미를 설치하고 우리 조직에 맞게 설정해줘.

AI가 조직 이름, 공간 목록, 캘린더 연결 여부 등을 한 번에 하나씩 물어봅니다. 무엇인지 모르겠다면 `잘 모르겠어요`라고 답해도 됩니다.

처음에는 `회사 내부용`을 선택하는 것이 가장 쉽습니다. 이 설정에서는 이메일과 관리 번호 없이 회사 Google 계정만으로 자신의 예약을 관리할 수 있습니다.

먼저 [START_HERE.md](START_HERE.md)를 읽으면 전체 과정을 쉽게 확인할 수 있습니다.

## 중요한 안전 원칙

실제 캘린더 주소, 시트 주소, 조직 정보는 공개 GitHub에 올리지 않습니다. 공개 템플릿과 조직별 비공개 설정은 분리되어 있습니다. 기본 권장은 회사 Google 계정으로 로그인한 사람만 사용하는 방식입니다.
