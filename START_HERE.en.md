# Start here: beginner guide

This system has two parts: a booking website for staff and an AI assistant used only for installation, updates, and troubleshooting.

## Prepare

Have the room names, each room's Google Calendar, your preferred access policy, and an administrator email available. Optional choices include Google Sheets logging, confirmation email, personal calendar events, and Google Meet links. If you do not know where to find a value, say `I don't know`; the agent will show the next place to click.

## Install

Paste the repository link into Codex and say:

```text
Install the Space Booking Agent for my organization.
I am new to AI. Ask one question at a time and explain only the next step.

https://github.com/hchanhee-cmd/space-booking-agent
```

Choose the recommended internal-company preset unless you need public or external booking. The agent previews masked settings and asks before writing configuration or changing a deployment.

## Test before launch

Open the deployed page, switch between `한국어` and `English`, check availability, make one dedicated test booking, test a deliberate conflict, verify your own-booking or token lookup, reschedule the test, and cancel it with approval.

The normal booking website does not require staff to open the AI assistant.
